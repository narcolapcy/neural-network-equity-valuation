# Input data dictionary

The dictionary describes concepts in the thesis. It is not an export of a licensed data product. Final field definitions and units must follow a separately authorized source and the original training implementation.

| Proposed field | Concept |
| --- | --- |
| company_id, year | Company-year key; preserve listed-company identifiers as text |
| roa | Return on assets |
| roe | Return on equity |
| gross_margin | Gross profit margin |
| ebit_margin | EBIT margin |
| receivables_turnover | Accounts receivable turnover |
| current_ratio | Current ratio |
| quick_ratio | Quick ratio |
| sustainable_growth | Sustainable growth rate |
| equity_growth | Growth in shareholders' equity |
| book_value_growth | Growth in net assets/book value, following the original definition |
| digital_patents | Count of digital-economy patent applications |
| top1_ownership | Largest shareholder's ownership fraction |
| top5_ownership | Top-five shareholders' combined ownership fraction |
| top10_ownership | Top-ten shareholders' combined ownership fraction |
| equity_market_value | Target equity market value; document currency and scale explicitly |

For new research, retain source dates, reporting periods and publication dates separately. Do not assume accounting-period end equals market availability. Raw records, vendor identifiers and data-access credentials are not provided.
