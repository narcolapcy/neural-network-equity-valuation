# Neural Network Equity Valuation

**Liuyu Xiong · Undergraduate thesis · April 2025**

An academic valuation study of A-share software companies combining financial fundamentals, digital patents and ownership characteristics with a feedforward neural network.

## Research at a glance

- **388 companies**, with the source thesis covering **2011–2023**.
- **14 input indicators** and **four extracted factors**, explaining **71.854%** of variance.
- **Reported test R²: 0.9800; MSE: 0.0099**, transcribed from the thesis rather than independently replicated here.
- Yonyou Network case: **RMB 26.84bn** estimated value versus **RMB 25.52bn** observed value (**5.17%** difference).

## Reproducibility

This is a **documented research case**, not an executable replication. A complete training implementation, fitted model and exact split were not recovered from the reviewed materials. No replacement code is misrepresented as the original work. Licensed CSMAR observations are not distributed.

The reported fit is not evidence of trading alpha or a verified out-of-sample investment return. The model specification and validation limits are explained in the report.

Academic research only. No investment recommendation or third-party endorsement is implied.
